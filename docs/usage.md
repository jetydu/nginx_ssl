# Nginx SSL Manager 使用说明

## 1. 新建证书

1. 进入“证书管理”页面，点击“新建证书”。
2. 域名支持普通域名和通配符，例如：
   - `example.com`
   - `*.example.com`
   - 多个域名可每行或逗号分隔，第一个作为主域名。
3. 填写联系邮箱、自动续期、自动部署等选项。
4. 点击“创建并申请”。

## 2. 验证方式

### HTTP-01（普通域名）
- 系统自动写入 nginx 验证路径。
- 要求域名解析到本机，且 80 端口可从公网访问。

### DNS-01（通配符域名，如 `*.example.com`）
- 系统会弹出 `_acme-challenge` 的 TXT 记录名称和值。
- 请到域名服务商（如阿里云 DNS）添加对应 TXT 记录。
- 等待 DNS 生效后，点击“我已添加，继续验证”完成签发。

## 3. 续期

- 普通证书：点击“续期”自动重新申请。
- 通配符证书：点击“续期”重新生成 DNS 订单并按提示添加 TXT 记录。

## 4. 部署到 Nginx

- 证书状态为有效后，点击“部署到 Nginx”。
- 系统会更新匹配的 server 块并执行 `nginx -t`，失败自动回滚。

## 5. 从 Nginx 导入

- 点击“从 Nginx 导入”，自动读取现有 nginx 证书并建立管理记录（自动续期默认关闭）。

## 6. 查看与编辑

- 点击域名查看详情。
- “编辑配置”可修改域名、路径、邮箱等。
- 编辑为通配符域名时会自动切换为 DNS-01 并关闭自动续期。

## 注意事项

- 通配符证书只能使用 DNS-01 验证。
- DNS-01 验证期间请勿删除 TXT 记录，直到签发完成。
- 修改证书路径后需重新部署到 nginx。
